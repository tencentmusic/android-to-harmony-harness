# Android/Harmony Live-Feature Profile

用于包含实时互动或长链路页面的双端项目。所有业务事实必须从当前授权源码、配置、可复现状态和设备证据中恢复；本文件不包含具体产品、域名、账号或协议值。

## 路径

- Harmony 根：`${HARMONY_ROOT}`
- Android 根：`${ANDROID_ROOT}`
- 分析输出：`${ANALYSIS_OUTPUT_DIR}`

## 行为与网络

- 先确认页面入口、状态、事件分发、连接生命周期和失败分支，再形成迁移闭包。
- 网络请求统一通过目标工程的 Repository/Network 封装，URL 从配置读取，业务文件禁止硬编码。
- 连接命令、事件名和参数必须从当前源码或运行证据核对，未知值保留人工确认点。

## 验收

实现后同时检查宿主接线、公共组件调用链、构建产物和设备行为。静态检查或合成适配器通过不能替代真实业务验收。
