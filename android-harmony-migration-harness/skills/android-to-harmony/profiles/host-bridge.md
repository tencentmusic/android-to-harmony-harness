# Android/Harmony Host-Bridge Profile

用于需要宿主桥接或跨模块导航的双端项目。具体模块、路径和协议由当前项目源码与配置决定；本文件不绑定任何真实业务。

## 通用约束

- 公共模块不得依赖宿主实现；宿主差异通过显式接口或 Navigator 注入。
- 网络、加密、签名和错误码沿用目标工程已有封装，接口地址来自项目配置。
- 先确认项目使用的状态管理版本，再按现有版本实现，不跨版本混用。
- 入口层只装配页面和依赖，业务规则留在 Model/Repository/ViewModel。

## 编译

按目标工程的 `build-profile.json5` 和路由返回的 `${BUILD_ARGV_PREFIX}` 执行同步、类型检查及受影响模块构建。
